## Course Project (Fisher)
By working on this project, I learned how to design and build an NLP system that solves a real problem. I learned how to handle scam messages in Indian languages using clear, rule-based methods, including normalising Unicode text, handling Indic scripts and Romanised code-mixing. I learned how to create transliteration suggestions and how to measure the performance of my system using source-wise metrics, error analysis and McNemar's test. I also learned about privacy by design when building browser extensions, as well as automated testing and continuous integration. Finally, I learned the importance of being honest about findings, being aware of limitations, and not making assumptions that the evidence cannot support.

Verified facts about Fisher (from the project report), usable on the site:
- Offline scam-signal checker for English, Hindi, Tamil and Telugu, including Romanized (Hinglish, Tanglish) text.
- Browser extension (Manifest V3) plus a command-line tool, sharing one rule-based engine; no network, storage or telemetry; one extension permission (contextMenus).
- Four results: high-risk patterns found, worth a closer look, no clear pattern match, could not analyze. "No match" never means safe.
- A transliteration module that returns several whole-word candidates per Romanized word.
- Evaluated per source group, with an error analysis and exact McNemar tests. Honest limitation: the central research question (several transliterations versus one) is not yet answered because the evaluation data has almost no Indic scam messages.
