# Dinesh Raj N · CSI4001 NLP Portfolio

A single-page course portfolio for CSI4001 Natural Language Processing (VIT, Fall Semester 2026-27, guided by Dr. Sharmila Banu K).

Built with Next.js (App Router), TypeScript, Tailwind CSS and `motion` (springs). It uses the system font stack, `next/image` for every image, and no analytics, trackers or cookies.

## Content

All copy comes from `content/portfolio.md`, mirrored in `src/lib/content.ts`. Change both together. Images live in `public/`.

The Hands-On Session outputs in `src/data/nltk-pipeline.json` are generated by real NLTK, not written by hand. To regenerate them:

```bash
python -m pip install -r scripts/requirements.txt
python scripts/nltk_pipeline.py
```

## Develop

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev          # http://localhost:3000
```

## Checks

```bash
npm run typecheck    # route types + tsc
npm run lint
npm test             # self-check for the simplified regex demo
npm run build
```

QA scripts (Playwright; run `npx playwright install chromium` once):

```bash
npm run build && npm start                                  # in one terminal
node scripts/shots.mjs http://localhost:3000 qa/shots       # 390/768/1440 × light/dark × motion/reduced
node scripts/frames.mjs http://localhost:3000 qa/frames     # frame sequences of key animations
node scripts/lighthouse.mjs http://localhost:3000 3         # mobile Lighthouse, 3 runs
```

## Deploy to Vercel

Choose one of the two options.

### Option A: from GitHub (recommended)

1. Create an empty repository on GitHub (no README, licence or .gitignore).
2. Push this project to it:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. Open https://vercel.com/new and sign in with GitHub.
4. Find the repository under **Import Git Repository** and click **Import**.
5. Leave the defaults: Framework Preset **Next.js**, Root Directory `./`, no environment variables.
6. Click **Deploy**. Every later push to `main` redeploys automatically.

### Option B: from the command line

1. Install the CLI: `npm install -g vercel`
2. Sign in: `vercel login` (opens your browser).
3. From the project folder, create a preview deployment: `vercel`
   - Set up and deploy? **Y**
   - Which scope? Choose your account.
   - Link to existing project? **N**
   - Project name: press Enter to accept, or type one.
   - In which directory is your code located? `./`
   - Want to modify these settings? **N**
4. Open the preview URL it prints and check the site.
5. Deploy to production: `vercel --prod`
